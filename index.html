📋 Link Your Google Sheet

You need to create a blank Google Sheet and paste its ID here. This avoids needing Drive API permission.

  1. 1 Open sheets.google.com → tap + Blank to create a new sheet
  2. 2 Rename it to Vehicle Fuel Log (tap the title at top)
  3. 3 Look at the URL — it looks like:
    docs.google.com/spreadsheets/d/XXXXX/edit
    Copy the long ID between /d/ and /edit
  4. 4 Paste it below and tap Connect Sheet
🔗 Connect Google Sheets

Sync your fuel log to a Google Sheet — automatically created in your Google Drive.

✅ 100% Free — No billing needed
⚠️ About the billing prompt: Google Cloud asks for a payment method during sign-up as identity verification only. The APIs used here (Sheets + Drive) are free within the daily quota — personal use like this tracker will never exceed free limits. You will not be charged.
  1. 1 Go to console.cloud.google.com and sign in with your Google account. Use the same Google account whose Drive you want to save the sheet to.
  2. 2 Click Select a project → New Project. Name it anything (e.g. Fuel Tracker) and click Create.
  3. 3 In the search bar type Google Sheets API, open it and click Enable. Repeat for Google Drive API. Both are free. No quota issues for personal use.
  4. 4 Go to APIs & Services → OAuth consent screen. Choose External, fill in App name (e.g. Fuel Log) and your email. Save & continue through all steps.
  5. 5 Go to APIs & Services → Credentials → Create Credentials → OAuth 2.0 Client ID. Choose Web application.
  6. 6 Under Authorized JavaScript origins, add the exact URL where you open this HTML file. If opening locally: http://localhost or null (for file://). If hosted online, use that URL.
  7. 7 Click Create. Copy the Client ID (ends in .apps.googleusercontent.com) and paste it below.
